# Fiche Google Play — Object Fonctionnement

## À publier en français (fr-FR)

**Nom (30 caractères maximum)** : Object Fonctionnement

**Description courte (80 caractères maximum)** :
Découvrez comment fonctionnent les objets du quotidien grâce à la 3D

**Description complète (4 000 caractères maximum)** :

Comprendre les objets du quotidien devient plus simple avec Object Fonctionnement.

Découvrez une collection de 9 objets courants à explorer à votre rythme. Chaque fiche explique leur fonctionnement, les principales pièces et les gestes essentiels pour les utiliser. Les simulations sont illustratives : elles ne remplacent jamais les consignes des fabricants.

EXPLOREZ LES MÉCANISMES EN 3D

Faites pivoter les modèles avec le doigt, zoomez et observez les pièces internes grâce aux vues pédagogiques. Découvrez 27 composants expliqués en français et suivez une visite guidée pour comprendre leur rôle.

MANIPULEZ LES APPAREILS

La bouilloire, le grille-pain, le ventilateur, le cadenas, la pompe à vélo, la cafetière, la lampe de poche et le lave-linge disposent de commandes interactives. Réalisez les gestes dans le modèle 3D et observez leur effet sur la simulation.

APPRENEZ EN PRATIQUANT

Huit défis pratiques proposent de réaliser des actions dans le bon ordre. L'application vérifie la progression à partir de la simulation. Répondez aussi à des quiz pour vérifier vos connaissances.

RETROUVEZ VOS PROGRÈS

Conservez vos favoris, les visites terminées, les réponses validées et les défis réussis directement sur votre appareil. Consultez le glossaire et retrouvez rapidement les objets à réviser.

FONCTIONNE SANS INTERNET

Toutes les principales ressources pédagogiques et les modèles 3D sont intégrés à l'application. Aucun compte utilisateur n'est nécessaire.

Object Fonctionnement est un outil de découverte pédagogique : les appareils sont schématisés, leurs animations sont simplifiées, et les exemples ne constituent pas un guide de réparation ni une notice de sécurité.
